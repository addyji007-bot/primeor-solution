# Day 4 — Feature Engineering & Deeper EDA

## Overview

Day 4 focuses on Feature Engineering and Deeper Exploratory Data Analysis (EDA).

After completing the data cleaning and basic analysis tasks in the previous days, the objective of Day 4 is to create additional analytical features and use them to perform deeper analysis.

The newly created features will also prepare the dataset for future analysis using PostgreSQL, Power BI, and forecasting techniques.

---

# Objectives

The main objectives of Day 4 are:

1. Create analytical features from existing columns.
2. Analyze shipping performance.
3. Analyze profitability at different levels.
4. Prepare the dataset for monthly and quarterly analysis.
5. Investigate the relationship between discount and profit.
6. Perform detailed sub-category analysis.
7. Identify and investigate potential outliers.
8. Save the feature-engineered dataset for future analysis.
9. Generate visualizations to support the analysis.
